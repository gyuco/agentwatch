# Test strategy

1. Identify changed behavior and plausible regressions.
2. Inspect existing test tools and conventions before proposing new ones.
3. Prefer focused tests first, then broader checks when risk justifies them.
4. Include error paths and boundary conditions relevant to the change.
5. Report what was verified, what failed, and what remains unverified.
